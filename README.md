# ASK_EMILY

I’m thrilled to showcase Ask Emily, a comprehensive travel assistant designed for road trip enthusiasts and RV travelers. This project simplifies travel planning with innovative features, all while being offline-capable and operating without external APIs like Google Maps.

🌟 Key Features:
Bridge Data Lookup: Access static bridge height and clearance information for safe travel.

Simulated GPS Routing: Generate step-by-step travel directions between locations.

Technician Finder: Quickly locate RV technicians by location and required services.

AI Chatbot: Get assistance with travel queries via a custom rule-based chatbot.

💻 Technologies Used:
Python (Flask), JSON, HTML/CSS, and a modular design to ensure scalability and user-friendliness.

🌍 Impact:
This project provides a reliable, offline solution for road travelers, ensuring seamless trip planning even in areas with limited internet connectivity.

I’m proud of the problem-solving and technical skills I applied during this project, from designing user-friendly interfaces to implementing offline functionalities.
